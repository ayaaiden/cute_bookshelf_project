A React application for tracking reading list and saving personal notes on favorite books. 

## ◽️ Features ◽️
* **Track Books:** Add books with their title, author, and current reading status (To Read, Reading, Completed).
* **Leave Notes:** Add multiple comments or notes to any book on your shelf.
* **Persistent Storage:** Your library is saved automatically to your browser's Local Storage, meaning your books will still be there when you refresh or close the page.
* **Cozy UI:** Styled with a custom pastel color palette using pure CSS Flexbox.

## 🏗️ Tech Stack 🏗️
* **Frontend:** React  + Vite
* **Language:** TypeScript 
* **Styling:** CSS Modules
* **Testing:** Vitest & React Testing Library
